# Ramsetu Constructions — Beyond the Blueprint (Concept V2)

Independent, unofficial demonstration website inspired by the spatial/editorial interaction language of the supplied Stanzza reference recording. It is not an official Ramsetu website, nor an exact reproduction of Stanzza.

## Run

```bash
npm install
npm run dev
npm run build
```

Deploy as a Vite project on Vercel (`npm run build`, `dist`).

## What's interactive

- Custom animated architectural SVG elevation at the opening (no stock sketch).
- Three expanding, image-led disciplines; click/tap to open.
- Interactive featured-gallery controls.
- Scroll-triggered editorial copy/image reveals and subtle image motion.
- Mobile-specific accordion layout for disciplines and menu navigation.
- Accessible reduced-motion handling and expandable FAQ.
- Original Ramsetu logo file carried forward from concept V1.

## Content caveats

Published Ramsetu assets are currently loaded directly from `https://www.ramsetuconstructions.com/assets/images/`. These need an internet connection and may fail if the original host moves/removes files or disables hotlinking. Replace with licensed local project photographs before a public/client launch. Project headlines are editorial placeholders, not verified project names. No before-after visual claims, completed-work claims, prices, timelines, or invented testimonials.
